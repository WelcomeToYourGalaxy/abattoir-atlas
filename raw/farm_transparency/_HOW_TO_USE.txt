Farm Transparency Project exports.

Drop one file per country here. The parser reads .csv, .kml and .gpx.

Prefer the CSV export
---------------------
The CSV carries 20 structured fields -- street number, street, suburb, state,
postcode, species, status, owner, contracted-to. The KML and GPX pack all of
that into one prose description that has to be pulled apart with regexes, and
they omit the address components entirely.

KML and GPX are the same data as each other. If you have both, keep one.

Ask Farm Transparency for a CSV export of any country where you only have KML.

Country
-------
The CSV names the country per row, so no flag is needed -- one file per country
is just tidier. The KML and GPX do not name it, so the parser has to be told,
which is another reason to prefer CSV.

Files held: us.csv, au.csv, ca.csv. Farm Transparency also publishes other
countries; drop any new export in here and re-run.

What lands in the atlas
-----------------------
Every FTP record carries a coordinate the project verified, so these skip
geocoding entirely and appear on the map immediately.

Only "Slaughterhouse" and "Knackery" are recorded as slaughter. A meat farm is
not a kill floor, and the rest are left slaughter-unstated rather than denied --
FTP does not assert that no animal dies on a farm, so neither does this.
